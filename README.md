# Golfin' Garage · /see-it video page

A preview of `build.golfingarage.com/see-it` for review, before Ayush or Inaam build it in GHL.

| File | What it is |
|---|---|
| `index.html` | Review page: desktop and mobile frames, "Launch day" and "All sections" views, and build notes |
| `page.html` | The page on its own |
| `ghl-custom-code.html` | Paste-ready code for one GHL Custom Code element |
| `docs/see-it-brief.md` | Structure, design, copy, the video list, build steps and open decisions |

**Watch the videos from the GitHub Pages link.** YouTube only plays them on the page when the page comes from a website. A copy opened as a file on your computer shows YouTube's Error 153.

`?review=1` on `page.html` shows every video slot, including the ones still waiting to go on YouTube, plus Finley's draft note. On the live page those stay hidden until they have content.
